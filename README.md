# MiniBank

Учебный проект на C# по мотивам базовых функций Eskhata Online.
Создаётся параллельно с изучением C# и backend-разработки.

Это самостоятельный учебный проект, не связанный с Банком Эсхата.
Все операции выполняются с виртуальными деньгами.

## Реализовано

- Консольное меню на русском языке.
- Просмотр баланса.
- Пополнение и снятие средств.
- Перевод получателю по номеру счёта.
- История успешных операций с датой, временем и суммой.
- Отдельные записи входящих и исходящих переводов.
- Проверка ввода суммы и достаточности средств.
- Проверка номера счёта и имени владельца при создании.
- Создание счёта через меню с проверкой уникальности номера.
- Номер связанного счёта в истории переводов.
- Переключение текущего счёта через меню.
- Просмотр списка счетов с номерами и именами владельцев.
- Фильтрация истории по точному названию типа операции.

## Технологии

- C#
- .NET 10
- Git и GitHub

## Запуск

Нужен .NET 10 SDK.

В папке репозитория выполните:

```bash
dotnet run --project MiniBank.ConsoleApp
```

Также можно открыть MiniBank.slnx в совместимой версии Visual Studio
и запустить проект MiniBank.ConsoleApp.

## Ограничения

Данные хранятся в памяти и сбрасываются после закрытия программы.
Регистрация и авторизация пока отсутствуют.
